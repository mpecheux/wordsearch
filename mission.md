Mission : 
Réaliser un jeu en js qui tient dans une page 'index.html'

Jeu : 
Mot mélés

Le jeu affiche un cube de 5 cases sur 5. Qui est un assemblage de 5 grilles 5x5 de mots mélés. 
Dans ces grilles se trouvent des mots de 5 lettres provenants de la liste ./mots.txt
Lorsque le jeu démarre un des mots présent dans le cube est affiché à l'utilisateur. L'utilisateur doit retrouver le mot dans le cub en cliquant/touchant les lettres qui le compose dans l'ordre. 
Si le mot est trouvé, un nouveau mot s'affiche. 
Le temps de jeu est de 60s, le joueur doit trouver un maximum de mot pendant ce laps de temps. 
A la fin du temps imparti, le score est affiché à l'utilsateur, il correspond au nombre de mots trouvé. 
Ajoute la possibilité de relancer une partie. 
Ajoute la possibilité de skipper un mot
Lors du démarrage d'une partie lance un compte à rebourt de 5secondes. 
L'utilisateur doit pouvoir faire tourner le cube pour voir toutes les faces.
Un mot peut être écrit de gauche à droite, de droite à gauche, de haut en bas, de bas en haut et être à cheval sur 2 faces.


Contraintes : 
Le jeu doit fonctionner aussi bien sur navigateur pc que sur mobile.
Les contrôles étants souris pour le pc, écran tactile pour le mobile.
